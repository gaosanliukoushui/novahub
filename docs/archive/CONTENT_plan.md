# 高并发内容平台早期构想归档

> 本文件是 NovaHub 立项阶段的方案草稿，保留用于说明项目演进过程。当前实现以 `README.md`、`PROJECT_OVERVIEW.md` 和源码为准。

早期目标是做一个类似社区/内容平台的后端系统，重点覆盖：

- 用户、内容、点赞收藏、评论、Feed、热榜、搜索。
- Redis 缓存、Kafka 异步事件、Elasticsearch 搜索、MySQL 持久化。
- Docker Compose 可复现部署和可演示前端。

当前项目已经在上述基础上补充了演示数据、静态单页前端、标准分词搜索降级、热榜 DB 回落、压测报告、架构文档和管理演示入口。
